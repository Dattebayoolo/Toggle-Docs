      Urdu Typing

      Toggle Docs ships with a built-in Phonetic Urdu keyboard. Press Alt+U in the editor to open the virtual keyboard. Nastaliq and Naskh fonts are loaded offline.

      Use Ctrl+Shift+R in any paragraph to switch it to RTL Urdu direction instantly.

      Markdown shortcuts

      Type # + Space for Heading 1, ## for H2, - or * + Space for bullets, 1. for numbered lists, > for blockquote, --- + Enter for horizontal rule.
